# 🌐 Usability Web Portal

A clean, responsive, frontend-only web application dedicated to exploring interface usability principles.



---

## ✨ Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
- **Modern UI/UX:** Clean aesthetics built with modern CSS practices focusing on accessibility.
- **Interactive Elements:** Dynamic client-side features powered entirely by vanilla JavaScript.

---

## 🏗️ Built With

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styles, layout designs (Flexbox/Grid), and animations.
- **JavaScript (ES6):** Client-side interactivity.
